# Print Ready Dev

Design useful 3D-printable parts with real OpenSCAD previews, an interactive STL viewer and printable downloads. This development package connects only to https://dev.printreadyparts.com/mcp. It shares the Print Ready modeling and welcome skills with the existing plugin.

Upload this ZIP under Customize > Plugins > Add > Upload plugin. Open the plugin's Connectors tab and add or connect Print Ready Dev. Make a 40 by 20 by 6 mm plate with a centered 6 mm hole. Ask to see the part and download its STL.

Create and inspect parts as a guest. Sign in through the connector to save models or printing preferences. Read https://dev.printreadyparts.com/welcome for examples. This is a development test, and public directory submission is pending. The public distribution repository includes the proprietary plugin license.
