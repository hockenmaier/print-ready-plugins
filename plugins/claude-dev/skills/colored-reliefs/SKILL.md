# Colored reliefs

Choose a relief when the design reads from the front and a few flat colors can describe the shapes. For an object with measured mating features, model those features with the Print Ready skill and use this workflow for the artwork if needed.

1. Choose the print size, cut line, and four ink colors including the base, unless the user specifies a different count. Use the user's loaded colors. Assign each major region, outline, and lettering to one of those inks before prompting. Call the host's ImageGen first for every design, with any supplied reference attached. Use the prompt below. If ImageGen cannot run or accept the reference, stop before tracing. Send only generated artwork to Print Ready.
2. Inspect the generated art. Check exact lettering and numbers, the physical cut line, and which ink fills each region. Use an ImageGen edit that names the specific region and replacement ink when a filled region uses an extra color. Ask it to keep all correct geometry and colors. Fix wrong lettering or a white mat before proceeding. Ordinary edge pixels and small shade variations can be flattened by Print Ready.
3. Check the selected connection with `get_capabilities`. If an explicitly selected connection is unavailable or reports a different environment, stop. Call `prepare_model`. For a shaped print, run `refine_artwork` on the full generated PNG with the ordered `palette`, `footprint: "silhouette"` and the canvas settings below. Set `imagegen_used: true` to check that the canvas clears on all four sides. Poll `get_model` and inspect its flattened PNG. Confirm the outline, transparent corners, and all intended color regions. If an intentional color substitution is needed, retry refinement with `color_map` and check the result. Keep the ordered palette explicit. Do not omit it or switch to automatic color picking to make a failed job pass.
4. Use the approved refinement handle as `artwork` in `create_colored_relief` with a new preparation, the ordered palette, `width_mm`, brief, decisions, and `imagegen_used: true`. Keep `footprint: "silhouette"` and omit the canvas settings for this cropped handle. For a full rectangular design that already passes visual inspection, send the generated PNG directly to the combined tool. Use the host file field when available, or a reachable HTTPS URL or PNG data URL. If the host cannot transfer the export, ask the user to download and attach that generated PNG. For size or height revisions, reuse approved artwork and supply `previous_model`.
5. Poll `get_model` and compare the model's top preview with the approved artwork. Check the footprint and width, ink assignment, text, and small gaps. Once they match, call `show_model` and offer separate STL and 3MF downloads. Report planned filament changes when useful. If the viewer cannot open, give the actual preview and both links from `get_model`.

## Canvas and cut line

Use real transparency when the host can request and export it. Ask for an empty alpha margin around all sides and omit `exterior_color`. If the export has a white or checkerboard pattern baked into opaque pixels, switch to the key below.

Otherwise use a single saturated key color that is absent from the print, typically hot magenta `#FF00FF` for blue, green, yellow and white artwork. If magenta or a similar ink is in use, choose a distant key such as cyan `#00FFFF` or lime `#00FF00` after checking all the inks. Pass the key as `exterior_color`, separate from the filament palette. If the host does not expose that field, use one of these three exact key colors in the prompt. Checked refinement detects a reserved key at the corners and verifies that it clears all four sides. The first pixel inside the margin should be the intended outer edge. Ask for no mat, halo, outline, or shadow between that edge and the canvas. If refinement leaves a mat, edit the generated PNG with ImageGen to extend the key or alpha right up to the intended edge. Never deliver the mat as geometry.

## ImageGen prompt

Fill in the bracketed fields. Name the ink used for each feature. White and black count as inks if used. For shaped art, fill the canvas field with either "Export a PNG with real transparency outside the cut line, with empty space on all four sides" or "Use a flat [key name and hex] margin about 8% wide on all four sides. Use this color only outside the cut line." Omit the canvas field for full rectangular art.

> Flat production artwork for a [count]-ink screen print. Draw [subject and layout], straight on, with [aspect ratio]. [Use the attached reference for its layout and recognizable features.] The cut line is the outer edge of [shape, corner treatment, edge ink]. Use exactly these opaque spot inks inside that edge: [names and hex codes]. Use [base ink] for the base. Use [one named ink for each main feature, border if desired, and lettering]. Text, verbatim: [quoted text, or no text]. Reuse these inks for every area, including outlines, gaps and highlights. Draw closed shapes with broad strokes, clean edges and flat fills. No tints, gradients, texture, gloss, shadows, bevels, depth or product mockup. [Canvas instruction.] The canvas meets the cut line directly. No outer frame, mat, halo, stroke or shadow past that edge. Do not draw color swatches or crop marks.

## How to keep swaps low

Use one continuous Z band per color. Every point on the print face shows its assigned color. That material extends down to the next transition. Each lower band supports the footprints of every band above it. Print Ready checks both ends of each compiled band against the flattened artwork, allowing small shifts at smoothed edges. Four colors take three planned changes, with the first material already loaded. Apply one print profile to the whole relief. The defaults are a 0.20 mm first and regular layer, eight base layers, and four layers per raised color. Honor a supplied printer profile's first and regular layer heights. Each band should contain enough layers to print reliably and hide the filament beneath it.

Use the Bambu-compatible format when Bambu Studio is the target. Bambu Studio can map the imported colors to filaments. Use standard 3MF with core materials when the slicer is unknown or the user requests it. Both formats use the slicer's printer profile. Set the band heights for that profile and tell the user the matching layer height when it matters. Keep the base and bands together in one object. Create unrelated pieces such as separate milestone tokens as their own objects.

For a design that needs colors at the same height, or parts the user needs to scale independently, use `create_3mf` with named model handles and material colors. Provide a shared `object` name for bodies that need to keep their registration. The independent 3MF tool also works with ordinary CAD models.
