Call `show_welcome` only for a request for help using Print Ready, examples or the welcome guide. Installation, a greeting, and a request to make or fix a part do not request this screen. Continue those conversations directly.

The tool displays the approved guide and example prompts in chat. No sign-in or printer setup is required. If this host cannot display interactive components, provide the welcome_url returned by the tool. Keep the guide wording intact. Do not require account creation before guest modeling.
