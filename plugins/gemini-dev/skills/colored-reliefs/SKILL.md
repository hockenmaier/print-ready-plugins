# Colored reliefs

Choose a relief when the design reads from the front and a few flat colors can describe the shapes. For an object with measured mating features, model those features with the Print Ready skill and use this workflow for the artwork if needed.

1. Use the requested size or choose a reasonable width in millimetres. Start with four colors including the base. Use fewer when the artwork needs fewer. Use the colors the user says are loaded. If the user specifies more supported filaments or asks for additional manual changes, use that count within the tool limit. Pick a contrasting base and put the colors that need the most visual emphasis higher. Handle color order and layer planning for the user.
2. For new artwork, call the host's image generator. Specify the color of the background, border, lettering and main shapes using the chosen filament colors. Ask for straight-on art, hard edges, solid fills, exact lettering and broad details. Exclude gradients, shading, texture and mockup backgrounds. Ask for transparent space outside a cutout. Send the PNG intended for printing directly to Print Ready. Reference photos may inform the image prompt.
3. Check the Print Ready connection with `get_capabilities`. Call `prepare_model` and keep its credentials. Submit the generated or supplied PNG to `create_colored_relief` with the ordered palette, width, and the user-facing brief and design decisions. Prefer a host file input when the host can pass the image. Otherwise use an exported HTTPS URL or PNG data URL. If the host cannot export a generated image, ask the user to attach its PNG. Keep the same environment and preparation on retry. The combined call flattens the palette, traces the outlines, builds the height bands, and packages the print files.
4. Poll `get_model` and compare the real top preview with the flattened PNG and the artwork shown to the user. Check the color of each major region, legibility, letter holes and continuity around thin lines. If a generated region uses an unavailable color, regenerate with the loaded palette. For a deliberate substitution, use `refine_artwork` with `palette` and `color_map`, then inspect the PNG for merged features. Use Print Ready's mapping for this step. Show the corrected art when it differs from art already shown in chat. Use `trace_artwork` if you need to inspect the SVG or outlines. Pass the ready artwork handle to `create_colored_relief`. Use a new preparation and `previous_model` for a revision.
5. Call `show_model` for the ready relief. Deliver the 3MF for printing in color. The model response reports the planned filament order and change heights. Explain manual changes only when they apply. State the planned count as such unless the exact file was sliced with the target settings.

## How to keep swaps low

Use one continuous Z band per color. Every point on the print face shows its assigned color. That material extends down to the next transition. Each lower band supports the footprints of every band above it. Print Ready checks both ends of each compiled band against the flattened artwork. Four colors take three planned changes, with the first material already loaded. Apply one print profile to the whole relief. The defaults are a 0.20 mm first and regular layer, eight base layers, and four layers per raised color. Honor a supplied printer profile's first and regular layer heights. Each band should contain enough layers to print reliably and hide the filament beneath it.

Use the Bambu Studio format for slot assignments when that slicer is the target. Use standard 3MF with material colors when the slicer is unknown or the user requests it. Both formats use the slicer's printer profile. Set the band heights for that profile and tell the user the matching layer height when it matters. Keep the base and bands together in one object. Create unrelated pieces such as separate milestone tokens as their own objects.

For a design that needs colors at the same height, or parts the user needs to scale independently, use `create_3mf` with named model handles and material colors. Provide a shared `object` name for bodies that need to keep their registration. The independent 3MF tool also works with ordinary CAD models.
