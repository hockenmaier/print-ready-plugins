## Gemini CLI compatibility

This extension runs in Gemini CLI. Use the Print Ready MCP tools for actual geometry and files. Gemini sign-in does not establish Print Ready account ownership. Check get_capabilities or whoami before account-only work.

Gemini CLI may not display MCP Apps. Return the actual PNG preview and STL download link when an interactive viewer is unavailable. Never claim a viewer opened without host evidence. Keep guest model handles for follow-up tools. Request optional Print Ready sign-in only for the private library or printing preferences. Use image generation only when the host actually provides it.


Read the print-ready skill before designing a part. For examples, open https://printreadyparts.com/welcome.
